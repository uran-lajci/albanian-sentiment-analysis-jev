# albanian-sentiment-analysis-jev
Sentiment classification of Albanian COVID-19 Facebook comments with TypeSafe's Jev, using no training data. Compared with the 20 models of Kastrati et al. (2021), re-trained on the paper's own split: Jev reaches 75.7 weighted F1 on the test set, against 72.1 for the best re-trained model (mBERT). Includes data, code and report.
